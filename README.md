# Final-HMS-AI-project-
This is my final Hospital Management System with AI Doctor Consultation project 

A simple yet useful **Hospital Management System (HMS)** made with **Python**. It also includes a basic **AI-powered consultation system** that helps suggest the right doctor based on a patient’s symptoms.

The project was built and tested using **Google Colab**. It handles common hospital tasks like patient registration, appointment scheduling, billing, and even visual reports using graphs.

 Project Features

- Login system for admin and doctors
- Add, view, and search patient records
- Schedule and manage appointments
- Generate patient billing details
- AI-based doctor suggestion based on symptoms
- File-based storage system using plain `.txt` files (no database required)

 AI Module Description

- The AI module takes symptom input from the user
- Uses simple keyword matching with `if-else` logic in Python
- Suggests a relevant doctor department based on symptoms
- Example:  
  Input: `fever, cough`  
  Output: `Suggested Doctor: General Physician`

 Technologies Used

- Python 3
- Google Colab 
- Libraries: `os`, `datetime`, `random`, `colorama`
- Git and GitHub for version control

How to Run the Project

1. Clone the repository:  
   `git clone https://github.com/Hafsa-Fatima1/Final-HMS-AI-project-.git`

 File Structure
